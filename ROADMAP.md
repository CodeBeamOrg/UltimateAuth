## Our Direction

UltimateAuth aims to become a modern, unified, and extensible authentication and authorization framework for .NET.

Our development approach prioritizes **security, architectural consistency, developer experience, and real-world usability**.

We are building UltimateAuth incrementally, starting with a reliable authentication foundation and expanding toward production-ready infrastructure, advanced security capabilities, and a broader .NET ecosystem.

## Development Milestones

### Phase 0 — Foundation

**Status: Completed**

Establish the core authentication architecture, including sessions, authentication chains, tokens, flows, persistence abstractions, and server infrastructure.

The foundation provides the architectural basis for future capabilities without requiring fundamental redesigns as the framework evolves.

### Phase 1 — First Public Release (v0.1.0)

**Focus: A working, tested and documented end-to-end auth framework**

**Status: Completed**

Deliver the first usable version of UltimateAuth, including core authentication workflows, session management, user and authorization fundamentals, client integrations, and persistence support.

Provide comprehensive documentation, runnable samples, and practical examples to help developers understand and evaluate the framework.

### Phase 2 — Broader Adoption (v0.2.0)

**Focus: Complete product fundamentals**

Improve the stability and usability of public APIs while expanding authentication modes, credential policies, security controls, and integration testing.

Strengthen developer experience across supported .NET application models and make UltimateAuth easier to adopt in real applications.

### Phase 3 — Production Expansion (v0.3.0–v0.8.0)

**Focus: Security, scalability, and ecosystem growth**

Progressively introduce advanced authentication security, multi-factor authentication, improved infrastructure integrations, distributed persistence, and enhanced multi-tenancy.

Expand observability, audit capabilities, performance optimization, platform support, and migration tooling.

Each release will focus on a defined area while preserving architectural consistency across the framework.

### Phase 4 — Stable Contracts (v1.0.0)

**Focus: Long-term API stability and production confidence**

Establish a stable public API contract backed by comprehensive security reviews, integration and regression testing, hardened authentication flows, and mature documentation.

The goal of v1.0.0 is to provide a dependable foundation for applications that require predictable behavior and long-term maintainability.

### Phase 5 — Long-Term Evolution

**Focus: Advanced capabilities and community-driven growth**

Continue evolving UltimateAuth through advanced authorization policies, external identity integrations, extensible authentication providers, enterprise observability, and long-term support planning.

Our long-term vision is to make UltimateAuth a first-class authentication framework within the .NET ecosystem.

## Documentation, Samples & Identity Lab

Developer experience remains a priority throughout the roadmap.

UltimateAuth provides multiple ways to learn and evaluate the framework:

- **Documentation:** Architecture, concepts, integration guides, and API references.
- **Runnable Samples:** Complete applications that developers can clone, run, inspect, and modify in their own development environments.
- **Identity Lab:** An interactive sandbox designed to demonstrate real UltimateAuth authentication and authorization capabilities directly in the browser.

These resources will continue to evolve alongside the framework.

## An Open and Evolving Roadmap

**This roadmap is a direction, not a fixed commitment.**

Priorities, implementation details, release scope, and timelines may change based on security findings, technical requirements, real-world adoption, and community feedback.

Features may be introduced earlier, postponed, redesigned, or reconsidered when doing so improves the overall quality and sustainability of UltimateAuth.

We value architectural consistency and reliability over rushing features to meet arbitrary deadlines.

## Community & Contributions

UltimateAuth is developed openly, and community participation plays an important role in shaping its future.

We welcome bug reports, feature requests, architectural discussions, documentation improvements, and code contributions.

If you have an idea or a use case that could improve UltimateAuth, join the conversation through GitHub Issues and Discussions.
